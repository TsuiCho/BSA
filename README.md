# BSA: Business & Systems Analysis Projects Repository

Добро пожаловать в репозиторий BSA!
Здесь собраны учебные проекты и практические материалы по бизнес и системному анализу, включая полные циклы разработки требований для реальных систем.

## О репозитории

Этот репозиторий предназначен для:

- Хранения учебных проектов по бизнес и системному анализу
- Демонстрации полного цикла разработки требований
- Практического применения методологий анализа и проектирования
- Создания портфолио аналитических артефактов

## Структура проектов

### Основные проекты

**BOOK Project** - Система онлайн-записи в барбершоп
- **Декомпозиция**: Анализ предметной области и разбиение на компоненты
- **Стейкхолдеры**: Идентификация и анализ заинтересованных сторон
- **Требования**: AS-IS и TO-BE анализ, функциональные требования
- **Диаграммы**: DFD, SWD, ADSWD, диаграммы состояний
- **BPMN**: Моделирование бизнес-процессов
- **User Stories**: Пользовательские истории с проверкой по INVEST
- **Use Cases**: Варианты использования с основными и альтернативными потоками
- **Объекты и роли**: Моделирование данных и системы прав доступа
- **Функциональные требования**: Детальная спецификация функциональности

**DELI Project** - Система управления доставкой заказов
- **Декомпозиция**: Анализ логистических процессов
- **Стейкхолдеры**: Луковичная диаграмма заинтересованных сторон
- **Требования**: Контекст системы, потоки данных
- **Диаграммы**: Диаграммы потоков данных и состояний
- **BPMN**: Моделирование процессов доставки

### Методологии и подходы

Проекты демонстрируют применение:
- **Системный анализ**: Декомпозиция, моделирование процессов
- **Бизнес-анализ**: Анализ стейкхолдеров, формулирование требований
- **Проектирование**: Создание диаграмм, спецификаций, моделей данных
- **Agile подходы**: User Stories, Use Cases, критерии приемки

## Как использовать

1. **Изучение проектов**: Открывайте папки проектов для изучения полного цикла разработки требований
2. **Анализ артефактов**: Изучайте созданные документы - от декомпозиции до функциональных требований
3. **Практическое применение**: Используйте материалы как образцы для собственных проектов
4. **Развитие навыков**: Анализируйте подходы к решению аналитических задач

## Формат материалов

Материалы представлены в различных форматах:
- **Документы**: .docx с описанием процессов и требований
- **Таблицы**: .xlsx с данными, матрицами, спецификациями
- **Диаграммы**: .png с визуализацией процессов и архитектуры
- **Модели**: Структурированные описания систем и компонентов

## Ключевые компетенции

Проекты демонстрируют владение:
- Анализом и декомпозицией сложных систем
- Идентификацией и анализом стейкхолдеров
- Формулированием бизнес-требований
- Проектированием функциональных спецификаций
- Моделированием бизнес-процессов
- Созданием пользовательских сценариев
- Разработкой систем прав доступа
